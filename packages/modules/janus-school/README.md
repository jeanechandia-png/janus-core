# janus-school

Pieza LEGO de formación, 100 % offline.

- **Pista Founder:** 10 unidades (cómo funciona el software, Git/GitHub, publicar, n8n, IA y agentes, web 3D, seguridad, contenido y monetización, pensar como ingeniero de sistemas, hablar con un programador), más un glosario con analogías, cuestionarios y repaso espaciado (SM-2).
- **Pista niños:** sesiones cortas con movimiento, técnicas de matemáticas (amigos del 10, concreto-pictórico-abstracto, gestos numéricos, ábaco como juego, patrones) y guía para padres.
- **Honestidad:** cada técnica indica su nivel de evidencia. La evidencia del ábaco mental en aula es débil. No diagnostica TDAH ni etiqueta a nadie.
- **Estado:** el módulo es puro; el anfitrión guarda el progreso.
