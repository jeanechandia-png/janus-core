# marcus-aurelius-wisdom

Pieza LEGO autocontenida: Marco Aurelio (vida, Meditaciones, doctrina, citas, ejercicios antiestrés). Sin red, sin secretos, sin dependencias.

- **Fuente de las citas:** traducción inglesa de George Long (1862, dominio público), leída el 2026-10-18 en classics.mit.edu/Antoninus/meditations.html. El español es una versión libre de ese inglés; el griego no se consultó. La numeración libro.sección es la estándar y no era visible en la página fuente.
- **Estados:** `text-verified-long` y `attributed-unlocated`. Una frase atribuida nunca se presenta como literal.
- **Crisis:** ante lenguaje de riesgo devuelve `support_first`, sin citas.
- **Uso:** `import { selectGuidance, getProfile, dailyReflection } from './src/index.js'`.
- No es una herramienta clínica.
